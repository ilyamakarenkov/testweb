# Профком НТМК — современная версия сайта

Базовая версия сайта первичной профсоюзной организации ОАО «ЕВРАЗ НТМК» ГМПР.
Проект на PHP, мобильная адаптивная вёрстка, новостная лента как основа.

## Требования
- PHP 5.3+ (расширения: pdo, pdo_sqlite или pdo_mysql, fileinfo, mbstring)
- Веб-сервер (Apache/Nginx) или встроенный сервер PHP

## Установка
1. Скопируйте файлы в корень сайта.
2. Убедитесь, что каталоги `storage/` и `storage/uploads/` доступны для записи веб-сервером.
3. Откройте сайт в браузере — база данных SQLite создастся автоматически при первом запросе.
4. Войдите в админку: `/admin/login.php` (логин `admin`, пароль `admin123`) и смените пароль.

## Переключение на MySQL
В `includes/config.php` установите `DB_DRIVER` = `'mysql'` и заполните `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`. Таблицы создадутся автоматически.

## Структура
- `index.php` — лента новостей (главная)
- `news.php` — страница новости
- `about.php`, `contacts.php` — статические страницы
- `admin/` — админка (вход, список, создание, редактирование, удаление)
- `includes/` — конфиг, БД, функции, шаблоны
- `assets/` — стили и скрипты
- `storage/` — БД и загруженные изображения

## Безопасность
- Пароли хранятся в виде хэшей (password_hash).
- CSRF-защита форм.
- Подготовленные запросы (PDO).
- Каталог `storage/` защищён от прямого доступа к БД.
